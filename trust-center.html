Data

Three doors. Three different piles.

Live check

Anyone drops a saved message. Signet7 hashes it, reads the seal and the listing, and returns a result. The default path does not keep the raw letter. Recipients never install.

Company desk

The company names work emails, people, and listing keys. Signet7 does not keep a password for that account. Status lines from the app can show last-seen. Bodies do not.

Company app

Runs on the office computer that they set up. It sits on named work emails. Optional vault, if they turn it on, stays on that office computer. Signet7 cannot read those letters.

Security

How the product is built to fail closed.

Seals

Supported mail uses Ed25519. A torn seal fails the check. A pass means the protected words still match that key — not that the email is wise or safe to pay.

Unknown actions

The decision surface fails closed on an unknown action. Signet7 returns allow or block. The caller still has to enforce it.

Download

The zip is an unsigned preview. Windows SmartScreen and Mac Gatekeeper will warn. Using named work emails still needs a company account. Recipients should not download it.

Retention

How long it stays.

Letters

Not kept by default. Transient uploads are deleted after the check. There is no seven-year default. Counsel still decides what the company must keep.

Ask us to delete

Email justin.daines@signet7.io with the word Delete. Or call POST /api/v1/privacy/deletion-request on an operated instance. That purges transients. It does not silently rewrite historical hash rows.

Cancel

Checkout is not live. There is no converting trial. See Cancel.
