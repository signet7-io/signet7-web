The product

What Signet7 does

Signet7 answers two questions about an important email: has the wording changed since it was signed, and is the sender's address in that organization's listing? Anyone can ask, free and with no account — recipients are not required to install anything. An organization that wants its own outgoing email to be checkable runs Signet7 desktop on a few named work addresses.

Check

How to check a message

Save the original. Drop it on the live check. Recipients are not required to install.

  1. Save the original.
  2. Drop it here.
  3. Read the result: words match / words don’t / no seal. Then listed / not listed / listing doesn’t match this address.

No seal is ordinary mail. Checking does not create a seal.

Open the live check

Outlook, if you have it

If the pane is already on the ribbon, check the open message. Recipients without Outlook still use the website.

What gets created

You drop a message on the live check (or Signet7 desktop checks the named inboxes). Signet7 answers: words match or not, key listed or not, time of the check. You get a signed file. That file is the record.

Two companies can link. You list your address. They list theirs. Each of those emails gets its own listing. If you are using Signet7, the other company gets the free live check and an invite — they are not required to install Signet7 desktop. Recipients are not required to install.

What it is

Signing what you send

Signet7 signs your outgoing email so recipients can prove it arrived unaltered. You turn it on yourself, and you keep writing in Outlook, Apple Mail, or Thunderbird. Signet7 desktop only receives mail; it never sends on your behalf.

How signing is set up

Checking what you receive

No account and nothing to install. Anyone can check the email asking them to move money or change an account. One person or a thousand use the same page.

Signet7 desktop

An app on one office computer, covering a few named work addresses. It checks incoming email on those addresses, and signs outgoing email if you have turned that on. Ordinary email passes without comment; you only hear from it when a signature does not hold.

Optional encrypted records vault on that computer for money and account mail. You hold the recovery key. Cap is 10 GB. Warning at 50%. Export a zip before 90%. The public website check does not keep the letter. Recipients never use the vault. Not a court stamp.
