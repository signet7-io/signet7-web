Security

Security, in short.

Signet7 signs an email so any change to its wording can be detected, and lets the recipient check that signature without installing anything. Below is the short version for a reviewer. The long version is the Trust Center.

Read the full Trust Center See what is live today

The short version

Six things a reviewer usually wants first

What we store

Verifying an email does not keep the email. The upload is fingerprinted in memory and deleted after the check. There is no default multi-year archive.

What signs the email

Supported email is signed with Ed25519. Change one character and the signature no longer matches, so the check fails.

What happens on an unknown request

The decision interface refuses anything it does not recognise rather than guessing. Whatever calls it still has to honour that refusal.

Where we sit

Nowhere in your mail flow. Signet7 is not a mail gateway and does not filter, hold, or rewrite messages. Your email keeps working if Signet7 is down.

Certifications

None held today. No SOC 2, ISO 27001, FedRAMP, or StateRAMP, and no published penetration test. We would rather say so than imply otherwise.

The installer

The desktop app is an unsigned preview, so Windows SmartScreen and macOS Gatekeeper will warn on it. Recipients are not required to install it.

Report a vulnerability to samuel.sanderson@signet7.io, or see security.txt. Please do not attach exploits or live resident or customer data. What a result does and does not mean is on Reading a result. Subprocessors are on Data providers.
