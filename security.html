Security notes

Not a certification

How Signet7 is built to fail closed, not look certified.

Full desk: Trust center. This page is the short security list. No SLA. No SOC 2. No ISO. No FedRAMP.

In the running product

  • Supported mail uses Ed25519 seals. A torn seal fails the check.
  • Unknown actions on the decision surface fail closed. The caller still has to enforce.
  • Public check does not keep the raw letter by default.
  • Company desk uses a one-time email link, not a Signet7 password.
  • After setup, Signet7 starts at login on the office computer that runs it. Closing the window leaves it running.
  • Download zips are unsigned previews. SmartScreen and Gatekeeper will warn.

Not claimed

  • Independent crypto review is not closed.
  • Operated customer key custody in a cloud KMS is not the live download.
  • A managed public listing network is planned, not live.
  • This is not a penetration-test report.
