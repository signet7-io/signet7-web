What Watch doesIt sits on one inbox. Ordinary mail stays quiet. It shouts if a seal is torn, or if a named vendor arrives unsealed. It does not send. It is not Exchange.
What Watch does not doIt does not check every employee mailbox. It does not replace the live check for staff. Recipients never install it.
Uninstall / updateNot a product feature today. There is no Uninstall button and no Check for update. The Windows script unpacks an unsigned zip into %LOCALAPPDATA%\Signet7 and stops. files/latest.json names this preview; nothing upgrades you. Partners delete that folder by hand and download a new zip. Outlook is removed in My add-ins — that is Microsoft, not Signet7. Recipients never install, so they have nothing to uninstall. Do not call this set and forget.
