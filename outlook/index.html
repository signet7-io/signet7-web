Outlook

Sideload the hosted Outlook pane. Keep writing in Outlook.

These files live on signet7.io/outlook. Outlook on the web opens the pane in the browser. Outlook on Windows and New Outlook can load the same files. This is not Signet7 desktop. Check an open message. Seal outgoing mail with Sign and send email. That step attaches Signet7-sealed.eml. The Send button in Outlook on the web and the Send button in Outlook desktop do not seal. This pane is not a composer. Checkout is not live. Recipients who never sideload still use the live check.

Not AppSource IT pushes this pane, not the desktop
  1. Save manifest.xml.
  2. Open aka.ms/olksideload. My add-ins → Add a custom add-in → Add from File. The new Apps store cannot upload XML. Not AppSource. IT can also push this add-in from Integrated apps. Do not push Signet7 desktop to every laptop. Steps: IT push to laptops.
  3. Read mail as usual. Unsealed mail stays quiet. Compose: Sign and send email. Wait until the pane says a signed copy is attached, then press the Send button in Outlook.
  4. Anyone else: open Signet7-sealed.eml and drop that file on verify.signet7.io/email/verify. No account. No install. Table: Where the seal lives.
