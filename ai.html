AI use disclosure · 2026-08-19
DRAFT — NON-OPERATIVE

Signet7 does not hide artificial intelligence.

The product is cryptographic email evidence and an optional action gate. It is not a generative chatbot.

  • No large-language-model writes Signet7 replies, seals, or marketing claims.
  • The mailbox agent uses IMAP, Microsoft Graph, or a local folder. It does not call an LLM.
  • An optional policy engine can record whether a named action was allowed or blocked. That is a static rule check, not content generation.
  • If a later release adds a generative model, this page will name the model class, the purpose, the data sent, and whether customer content is used for training. Training on customer content is off unless a later written term says otherwise.
  • Verified is not safe. An AI or policy result is not a fraud verdict.
