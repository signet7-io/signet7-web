No install for the other side.

What the recipient does

Three steps. One result.

1. Save the email

Keep the original .eml. Forwarded copies can drop the protected headers. iPhone Mail often cannot export it; use a desktop if you cannot get the original file.

2. Open the check

Open https://qual.signet7.io/email/verify. No account is required. Verified is not safe. Unknown is not fraud.

3. Read the result

Matched, unmatched, or unknown. Verified does not mean safe. Unknown does not mean fraud.

What this page is not

A brochure is not a verifier.

GitHub Pages has no Signet7 API. Putting a paste box here would fake a product. The live verifier is https://qual.signet7.io/email/verify.
