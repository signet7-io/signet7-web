How install works

Sign up first. Then install. Not the other way around.

RecipientUse the hosted check. Do not install anything.
SenderPay or enroll. Receive a sender token. Then run the desktop or pip client.

Why not $4.99 per inbox?

Email trust spending validates the need. It does not define this category.

Businesses already pay monthly for domain, mailbox, and email-security controls. Signet7 should not enter that commodity comparison. The value is the sealed message and the evidence the recipient can check.
